{% extends "core/base_con_sesion.html" %}{% load iconos estaticos formato_inventario %} {% comment %}«Nuevo pedido de cotización» (CMP-RLZ-PED; ``VIEWS.c_pednew`` del prototipo). Un solo formulario que se vuelve a dibujar con cada botón (agregar o quitar un insumo, filtrar y seleccionar proveedores, habilitar un insumo, revisar), sin JavaScript y sin validar mientras se escribe (interfaz.md). Tres bloques: 1 qué necesitás (los insumos bajo el mínimo, el catálogo de tus invernaderos y, para un insumo que no está habilitado, «Habilitarlo»: extensión 3a.1a), 2 a quién se lo pedís (los proveedores activos, con el filtro propuesto por las categorías de lo que pedís) y 3 hasta cuándo reciben cotizaciones. El primer botón del formulario es «Revisar pedido» (oculto): es el que dispara Enter. Los errores vuelven junto a cada campo y lo escrito se conserva.{% endcomment %} {% block titulo %}Nuevo pedido · InfoPonia{% endblock %} {% block contenido %}
